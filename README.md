# HIMNA Law Consulting website

A responsive, single-page website prototype based on the supplied Figma file. It uses the original local Figma assets included in `assets/` and has no build step or package dependencies.

## Open the site

Open `index.html` in a browser. The page includes scroll-triggered section transitions, an animated hero and smoke layer, a scroll-driven gavel, a 3D practice-area card sequence, a staged approach timeline, and hover or focus reveals for the advocates.

## Current limits

- The enquiry form opens the visitor's default mail app with the message addressed to HIMNA; successful delivery depends on that app being configured.
- The practice-area cards use temporary typographic symbols; the exact Figma card illustrations were not available after the Figma connector reached its Starter-plan call limit.
